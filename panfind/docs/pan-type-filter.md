# 网盘类型筛选（v0.3.7）

## 行为

- 筛选芯片：百度 / 夸克 / 迅雷 / UC
- **实心 + ✓** = 已计入结果；**虚线 + –** = 已排除
- 点按已选芯片 → **立即排除**该类型并隐藏对应行（无需重新搜索）
- **全部排除（空选）** → 视为显示全部（芯片再次全亮）
- 重新搜索时 `cloud_types` 与当前筛选一致；空选则不传参（服务端=全部）

## 0.3.6 芯片误操作根因

「空选=全部」时，四个芯片都显示为选中，但点击实现是「空数组 `.includes(id)` 为假 → **加入**该类型」。用户在「全部」外观下点「夸克」本意是排除夸克，结果变成 **只选夸克**，于是「共 1 条」且仍是夸克。

0.3.7：空选先展开为全类型再做排除；样式用实心/虚线区分，避免再混淆。
