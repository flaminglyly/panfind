# 微博关键词硬过滤（v0.3.5）

## 规则

查询 **Q**（规范化：trim、NFKC、大小写、去零宽）须作为**连续子串**出现在：

1. **帖子正文**（含长文），或  
2. **产出该盘链的那条评论**

仅博主昵称不够。

### 中文无空格 = 整句

「王子的黑手党骑士」视为**一条短语**，不会拆成「王」「子」「黑手党」…  
正文只有「黑手党」或「锁爱游戏 / 吾岸」→ **直接丢弃**（不是降权）。

### 诊断

`sourceStats.weibo.detail` 可能含：

- `keywordDropped`：因短语不匹配丢弃的盘链候选数  
- `skippedOffTopic`：正文不含短语而跳过的帖数  
- 结果项 `weiboMatchField`：`post` / `comment`

## 验证

搜「王子的黑手党骑士」：不应出现仅「锁爱游戏 / 吾岸 / 无关资源库」标题；含完整剧名的帖/评应保留。health=`0.3.5`。
